BatchMath Site v8.39

Fix:
- Removed the automatic regex insertion of MathJax \\left / \\right delimiters from the shared Calculus Prep display renderer.
- That insertion could break nested expressions such as sqrt(arctan(x-3)), ln(arccos(x/4)), and other nested trig/log/radical combinations, producing MathJax's "Missing or unrecognized delimiter for \\right" error.
- Function arguments now use ordinary MathJax parentheses, which are stable under arbitrary nesting.
- This is a shared renderer fix, so it applies across every Calculus Prep engine that uses the common display-math pipeline.

Regression notes:
- AP Calculus and IM1 keep their existing MathJax implementations; their manually authored \\left / \\right pairs were not changed.
- Custom answer-entry editors/keypads remain unchanged.
