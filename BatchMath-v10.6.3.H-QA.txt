CHANGES
-------
1. Squeeze Theorem / Trigonometric Limits course practice
- Removed infinity-over-infinity / growth-comparison families from this engine.
- New intended mix is approximately 20% Squeeze Theorem and 80% straightforward trig limits.
- Squeeze families use bounded oscillatory factors multiplied by powers tending to 0,
  including x^p sin(k/x^q) and x^p cos(k/x^q) forms.
- Regular trig families include sin(kx)/x, x/sin(kx), tan(kx)/x, x/tan(kx),
  (1-cos(kx))/x, and (cos(kx)-1)/x.
- 50,000-sample targeted check: 19.784% squeeze / 80.216% regular trig;
  all 8 resulting variants observed; 0 infinity/log/exponential-growth problems; 0 generic fallback choices.

2. Enter-key advance convention
- AP Calculus and Calculus Prep now share a site-level convention: once feedback is shown
  and a Next Question / New Problem control is available, pressing Enter advances exactly once.
- IM1 is intentionally excluded from this convention.
- This fixes the Advanced Trigonometric Limits case after an incorrect response/explanation.
- All 62 AP Calculus instrumented engines and all 11 Calculus Prep instrumented engines load
  the shared PWA script containing this behavior.

3. Seeded browser QA harness
- Preserves the prior harness fixes: returns snap:s rather than undefined snap and expects 90 engines.
- Extended browser QA to verify the Enter-advance convention on AP Calculus / Calculus Prep engines
  and to fail if one Enter press generates more than one new problem.
