# BatchMath v10.7.19

- One-Sided Limits now displays fractional exponents with stacked fractions and separates piecewise limit prompts from their full function definitions for a cleaner layout.
- A sitewide math-display pass converts fractional superscripts to `\frac` notation in generated questions, answers, and explanations.
- Regular Squeeze/Trig practice removes coefficient `1` from trig arguments for every supported variable and prevents identical sine/cosine numerator-denominator ratio problems.
- The Advanced Trigonometric Limits focus selector now uses the same red-bordered color treatment as the other AP Calculus practice engines.
- Added regression coverage for sitewide fractional superscripts, One-Sided piecewise layouts, trig coefficient cleanup, and non-identical ratio generation.
