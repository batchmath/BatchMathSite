# BatchMath v12.8.R (Claude build)

Changes from v12.8.P:

- Limit and summation engine: explanations no longer use T(k,n) or S_n. They show the width, the right endpoint x_k, the definition of the integral as a limit of right-endpoint sums, the substituted expression, and (Part 2) the full evaluation with identity explanations. The keypad uses two integrated template keys (limit and sum); the Part 2 keypad has only digits, minus, fraction and the cursor/edit keys.
- Integrals Using Geometry: the graph is first in the worked explanation; trimmed keypad profile `unit4-geometry`.
- FTC: teacher-style steps (rule, differentiate, upper evaluation, lower evaluation, upper minus lower, simplify).
- Integral Rules: rule, original integral, apply, substitute, algebra, why it works, answer; limits are oriented explicitly.
- Chain Rule page: two added videos. Derivatives with Tables and Quotient Rule buttons are labeled "Homework Walkthrough".
- Fixed ambiguous implicit multiplication in FTC TeX (for example e^{4 2x^2}).
- New QA: tools/q-newton-explanations-qa.mjs, q-ftc-rules-qa.mjs, q-newton-keypad-browser-qa.mjs, q-geometry-browser-qa.mjs, q-ftc-rules-render-qa.mjs (browser tests need Playwright plus KaTeX or MathJax).
