# v12.8.P review build

This revision follows the October 28 brief for Geometry, FTC and Integral Rules and the requested short `batchmath-site-v12.8.P.zip` filename. It is a build for review, not a statement of user approval. It continues `dfe1f8a2ea8eff1e9cdc7cf2abe6c550aa59928f` on the existing N branch. Main, M, the existing N release, curriculum PDF mappings and the recent Newton engine are preserved.

## Changes

- Geometry identifies every region by interval and matching graph label. Linear and absolute-value graphs split at vertices and actual axis crossings; all dimensions and ordinary areas are nonnegative exact rationals. Each contribution gets its above/below-axis sign before addition. Circles show the radius and circular area; shifted arcs separately show the rectangle dimensions and addition/subtraction before the sign. Bare `x` has no outer parentheses, and the redundant answer prompt is removed.
- All seven Geometry families retain their weights. The full semicircle subset includes the existing `semicircle` family (15% of all questions) and the full arcs in `rectangle_circle` (20% times 70% = 14%). Sampling within these existing families produces one-third origin, one-third single shift and one-third both shifts overall. The horizontal/vertical split within single shifts targets 16:13 (approximately even). Shifted rectangles remain genuine rectangle/circle problems. Every category samples above/below the axis equally; nonzero vertical shifts are at least the radius in magnitude, so no arc crosses the axis. Quarter-circle families remain supported.
- FTC uses `H` for the integral function and `F` for an antiderivative, with `F'=f`. Each worked solution shows upper evaluation minus lower evaluation, differentiation (including constant zeros), substitution and the simplified derivative. Identity bounds omit multiplication by one. Natural coefficient/factor spacing and necessary negative-factor grouping replace ambiguous spacing.
- Integral Rules removes the preliminary orientation response. The requested integral is checked and scored once, using the existing single-question flow. Equal-bound questions show only the requested integral in the main question box. Existing equal bounds are numerical; no new symbolic-bound family was added. Reversal signs remain explained. Antiderivative warnings are removed.
- The shared practice component adds only three-engine CSS markers and guarded prompt suppression. Question and feedback boxes grow with rendered mathematics and diagrams. Editor/checker files are unchanged. Comprehensive Review inherits these three factories with its existing eleven-topic mix.
- App/PWA version metadata and the three affected pages plus Comprehensive Review are synchronized to P. The Newton page and generator source remain unchanged.
