## How to resume

1. `git fetch origin && git checkout claude/v12.8u-unit4-final-four-integrals`
2. Generators live in `assets/ap-topic-generators.js` between the `v12.8.U final four integrals engines START/END` markers.
3. Audit: `npm run qa:unit4-final-four` (12,000 seeded problems per engine, independent TeX-based verification).
