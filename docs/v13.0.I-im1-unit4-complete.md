## Answers and grading

**Every answer is typed**, in separate labeled fields:
- first term a₁; recursive rule aₙ =; explicit formula aₙ =; equation y =; x =; percent; growth or decay;
- MathLive fields with keypads that have each answer's keys (see the table);
- growth or decay goes in a plain text box (with the device keyboard on a phone).

| Field | Keypad keys (besides digits, −, decimal point, fraction, ←/→, ⌫, Clear, Check) |
| --- | --- |
| First term | a₁, = |
| Recursive rule | aₙ, aₙ₋₁, +, ·, ( ), = |
| Explicit formula | aₙ, n, exponent, +, ·, ( ), = |
| Equation | x, y, f(x), exponent, +, ·, ( ), = |
| Number, x =, percent | the number keypad |

**Formulas and equations are graded by value, not by spelling**, so every equivalent form is accepted:

| Kind of answer | How it is checked | Accepted examples |
| --- | --- | --- |
| Explicit formula | compared with a₁·rⁿ⁻¹ for n = 1…8 | a_n = 4(2)^(n−1), 4·2^(n−1), 2(2)^n, 2^(n+1), f(n) = … |
| Recursive rule | compared with r·aₙ₋₁ for several values of aₙ₋₁ | a_n = (1/2)a_(n−1), 0.5a_(n−1), a_(n−1)/2, or just ½a_(n−1) |
| Exponential equation | compared with b·rˣ for x = −2…5 | y = (12)(1/4)^(x−1), y = 48(0.25)^x, f(x) = …, y = f(x) = … |

- **Rejected:** wrong ratios, an off-by-one exponent (4(2)^n for 4(2)^(n−1)), arithmetic rules (aₙ₋₁ + 2), linear
  formulas, and a recursive rule typed where an explicit formula is asked for. A missing aₙ₋₁, or an x in a sequence
  formula, gets a specific message.
- **Writing different equations (3G):** each equation must be correct, and the same equation entered twice (respaced,
  or with 1/4 written as 0.25) is refused with "This is the same equation as Equation 1. Write a different form."
- **Numbers, first terms and solutions** accept every equivalent exact form (3/2, 1.5 and 6/4; 5 or a₁ = 5; 3 or
  x = 3). Rounded decimals of repeating values (0.333 for 1/3) are rejected.
- **Percents** accept 20 or 20%. **Growth or decay** accepts the word in any capitalization, and also grows/decays and
  increase/decrease.

**Mathematical care**
- **Exact values throughout.** Every value is computed with exact fractions, and context answers are exact decimals:
  whole counts, cents for money.
- **Indexing.**
  - A sequence's "end of hour 1" is a₁, and "the end of hour n" is n − 1 multiplications later.
  - An exponential model's "x periods since the start" makes the starting amount the value at x = 0.
- **Even versus odd gaps (3D).** Two terms an odd number of places apart determine r uniquely. An even gap (r², r⁴) has
  two real solutions, so those problems state "with a positive common ratio" or "negative"; no problem has two answers.
- **Recursive formulas always ask for the first term** as well as the rule.
- **Section 4:** no logarithms. Each number is written as a power of the base (a negative exponent for a reciprocal),
  and coefficients are divided out (or multiplied by their reciprocal) first.

**Behavior.** Unchanged from the Section 1 engines:
- the black/red/yellow design and MathLive fields;
- autofocus, Enter to check and Enter to advance after a correct answer;
- the Correct and Attempted counters, Next Problem and Reset Score;
- a worked, plain-language solution after every answer, and the complete correct response after a wrong one;
- Practice Type menus, reproducible problems (`?bm_seed=…`), and analytics engine IDs `im1_unit4_*` (the unit review
  is `im1_unit4_unit_review`).

## Rebuild and test

```bash
node tools/build-im1-unit4-pages.mjs
```

This writes the 49 Unit 4 pages (27 resource pages and 22 practice pages). Running it again changes nothing.

```bash
npm run qa:im1-unit4
```

This runs `tools/im1-unit4/section1-qa.mjs` (4,000 problems per engine and Practice Type) and
`tools/im1-unit4/sections2-4-qa.mjs` (3,000 per engine and Practice Type). Each problem is solved independently from its
question text with exact fractions. Grading uses the page's own checks, both on typed text and on MathLive LaTeX
through the Unit 4 contracts.

```bash
BM_PORT=<port> node tools/review-lab/im1/unit4-practice-browser.mjs
```

This answers all 22 engines and every Practice Type in the browser, on desktop and on a phone. It also enters a rule,
an explicit formula, an equation and a solution with the keypad alone.

```bash
BM_PORT=<port> node tools/review-lab/im1/unit4-section1-browser.mjs
```

This is the Section 1 regression.

```bash
BM_PORT=<port> node tools/review-lab/im1/unit4-browser.mjs
```

This checks the Unit 4 pages, menus, all 46 PDFs, practice buttons, the retired files, and the entry points.
