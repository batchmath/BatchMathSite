The change is described in `docs/v13.0.E-3d-cross-section-toggle.md`. All results below are from the code on
`claude/v13.0e-3d-cross-section-toggle` at `bafc547`. After it only docs, review-lab tooling and the route-sweep
artifact change, and the ZIP contains none of them. The branch was created from the v13.0.D branch, and the final

**The button label** was checked on every model:
- closed, it reads "Show 3D Model"; open, "Hide 3D Model";
- its accessible name follows it (for example "Show 3D Model: R revolved about the line y = 0");
- no text or accessible name inside any 3D control contains "Beta".

**The slice control** was checked on every model, in this order:
1. **Opening.** The model opens with the slice shown. The button reads "Hide Cross Section", "Hide Disk", "Hide Washer"
   or "Hide Shell", every slice object is visible, and the slice's yellow is on the canvas.
2. **Hide, after a rotation and a zoom.** It takes exactly 1 redraw. The canvas, the geometry buffers (by id), the camera
   and the display mode (Transparent) stay the same.
   - Every slice object is hidden: face, rim, slice line, marks or radii, and labels.
   - The button reads "Show …", and the legend entry is dimmed.
   - The slice's yellow pixels go from 2,187–111,298 to **0** in every model.
3. **Opaque while hidden.** The slice's faint hidden-line copies stay hidden (0 yellow pixels).
   - Show in Opaque brings back the slice and its copies (220 or more yellow pixels).
   - Hide again gives back the hidden Opaque picture **byte for byte**.
4. **Transparent while hidden.** The slice stays hidden, and the picture equals the hidden Transparent picture of step 2
   byte for byte.
5. **Reset view.** It returns to the starting view and keeps the slice hidden. Show then gives back, byte for byte, the
   picture of the model as it first opened.
6. **Keyboard** (all 15 desktop models). Enter on the control hides the slice and Space shows it again. The question
   stays: Enter does not go to the next question, including on calculator questions after Part A was checked.
7. **Hide the model and show it again.** Closing released every GPU geometry and texture (0 left). The reopened model
   still has the slice hidden.

**Two axes.** Each model has its own control. Model 1 kept its hidden slice while model 2 was opened, hidden and shown,
and model 2 opened with its slice shown. This was checked on both pages, at both sizes.

**Next question.** In all 14 cases the old models were removed and released: 1 or 2 per question, 0 geometries and 0
textures left, 0 canvases. The next question's control is closed and reads "Show 3D Model", and its model opens with
the slice shown.

**Layout.** No page is wider than the screen.
- **1366×900.** The help line and the three controls share one row when they fit (Solids of Revolution). With the longer
  "Hide Cross Section", the controls go on a second row.
- **390×844.** Transparent | Opaque is on one row, and the slice button and Reset view on the next.

## 5. Limitations

- **Testing.** There was no physical-device or assistive-technology testing. Touch was tested with real touch events in
  Chromium's device emulation. Safari and Firefox were not tested.
- **Button names on Solids of Revolution.** The button is named after the slice ("Hide Disk", "Hide Washer", "Hide
  Shell"), not "Hide Cross Section": a cylindrical shell is not a cross section.
- **Kept when the model is reopened.** Hiding the model and showing it again keeps the slice hidden, as the Transparent /
  Opaque choice is kept since v13.0.D. A new question starts with the slice shown.
- **The button's state.** The button changes its text (Hide … / Show …) and does not use `aria-pressed`; the canvas's
  description still mentions the highlighted slice while it is hidden.
- **The Comprehensive Review pages** do not show the 3D models, as before.
