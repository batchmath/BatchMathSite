### Investigations requested in 1.9
1. **Extra Separable Differential Equations #2** (dy/dx = cos x · e^(y+sin x), y(0) = 0; y = −ln(2 − e^(sin x))).
   **Confirmed error in the typed Answers PDF only.** The solution needs sin x < ln 2. The connected interval
   containing 0 is (−π − sin⁻¹(ln 2), sin⁻¹(ln 2)) ≈ (−3.9074, 0.7658). The typed answer gives the left endpoint
   sin⁻¹(ln 2) − 3π/2 ≈ −3.9465; on (−3.9465, −3.9074) the expression 2 − e^(sin x) is negative, so the solution
   is undefined there (checked numerically). The handwritten Solutions PDF (the one published on the site) has the
   correct interval.
2. **Differential Equation Reminders, Newton's Law of Cooling.** The sheet says k is always positive and to remove
   the negative in T − Tₛ = (T₀ − Tₛ)e^(−kt) when heating. **Confirmed sign-convention inconsistency.** With k > 0
   the same formula is correct for heating and cooling (for heating T₀ − Tₛ < 0, and the gap still decays). Dropping
   the negative only works if k comes out negative, as in the handwritten heating solutions (k = −ln 3 / 5), which
   contradicts "k is always positive". Final numerical answers are unaffected (Review #4: 30.5507 more minutes either
   way). The engines use T − Tₛ = (T₀ − Tₛ)e^(−kt) with k > 0 for both heating and cooling.

### Further observations (reported, not changed)
- Initial Value #8 handwritten key: y = x³ − sin⁻¹(x²) + π/4 "for [−1, 1]". dy/dx = 3x² − 2x/√(1−x⁴) is undefined
  at x = ±1, so under the prompt's definition (the solution must satisfy the original equation) the interval is
  (−1, 1). Initial Value #5's [0, π/2) is consistent with that definition (√x and the equation are defined at 0).
- Separable #2d (dy/dx = 4x³ tan y, y(1) = π/2): tan y is undefined at the initial point itself, so the equation is
  not satisfied at the initial condition; the key's sin⁻¹(e^(x⁴−1)) on [−1, 1] is not a valid IVP solution there.
  Generated practice avoids initial conditions at singularities of the equation.

### Interval-of-validity convention used by the engines
The maximal connected interval containing the initial x-value on which the particular solution is defined and
satisfies the original differential equation (prompt 7.8). An endpoint is included only when the solution and the
right-hand side are both defined there and the one-sided derivative matches (for example √x terms at 0, as in Initial
Value #5); a point where the equation is undefined (division by zero, vertical tangent, log of 0) is excluded.

## Fixed during Phase 8
`assets/answer-normalization.js` rewrote any answer field on a click of a "Check" button, pulling a leading minus out
of what it took to be a parenthesized fraction: `(-infinity,(1)/(2))` became `-(infinity,(1))/2`, so a correct
interval was rejected as unreadable. Unit 5 fields now carry `data-bm-no-normalize="true"` and the normalizer skips
such fields; every other page behaves exactly as before.
