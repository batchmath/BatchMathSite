Foundation: verified production F/main `0bf61ebd86ae0da06d9f9e4f580ab9b3d386a81a`. Branch: `hotfix/v12.9g-unit2-inverse-qa`; [draft PR #3](https://github.com/batchmath/BatchMathSite/pull/3). No main merge or deployment is authorized.

## Student-facing correction and preservation

The exponential and logarithmic inverse-function generators in both Unit 2 engines now say “Let g be the inverse of f.” The comprehensive review omitted that definition; the focused engine's underlying prompts used Unicode `g=f⁻¹` and its renderer already supplied an explicit definition. Cubic, linear and table prompts retain their original wording. Full-page byte guards allow only these four prompt strings. Mathematical parameters, answers, graders, explanations and distributions are unchanged.

The reproducible before/after audit confirms exactly **400 review failures = 218 false positives + 182 ambiguous prompts** on production F. The corrected assertion recognizes explicit named English, TeX and Unicode definitions and rejects missing definitions, different function names and incorrect inverse exponents. Both engines sample all five inverse families; **1,000 generated non-prompt contracts are identical before/after**. [Before/after evidence](unit2-hotfix/evidence/inverse-before-after.json), [page guards](unit2-hotfix/evidence/preservation.json).

G metadata changes 16 version-only files and two local test instructions. [Whole-site preservation](unit2-hotfix/evidence/website-preservation.json) compares every other tracked site/configuration file against F, including the Unit 6 feedback modules, graders, region models, MathLive/keypads, videos and IM1 content. No unrelated student runtime change is made.
