## Phase 0: W baseline inventory
`tools/review-lab/unit5/qa/inventory.mjs 300` (300 seeded problems for every family and tier). Calculator status is
set per generated problem in W, not per family:

| Engine | Calculator-active | Non-calculator |
| --- | --- | --- |
| Basic First-Order | `calculator_ftc` (15% of mixed; one template: f(b) from f' and f(a)) | the other five families |
| Motion | `calculator` (15% of mixed; intermediate and challenging only — no foundational tier) | recover, displacement/distance, direction/speed, multi-part |
| Slope Fields | none | all four families |
| Separable | none | all six families |
| Growth / Decay / Interest / Newton | all six families | none |
| Rate | almost everything | only about 35% of `one_rate` and `initial_change` foundational problems (two linear-rate templates) |

Variety (distinct problems among 300 per family and tier): most families 240–300; Slope Fields segments and curves
10–66 (a fixed table of equations); Separable trig challenging 91; Basic general solutions intermediate 191.

Numeric grading in W: `numeric` answers pass within a tolerance of the unrounded value (0.001 for three decimal
places, 0.005 for cents, 0.5 for whole numbers); calculator interval endpoints within 0.0015. A student answer
such as 1.234 for a true value of 1.2346 is accepted in W. Phase 1 replaces this.

Routes (W): seven Unit 5 practice pages — `topics/<topic>/practice/` for Basic, Motion, Slope Fields, Separable,
Growth, Rate, and `topics/comprehensive-review/assignment-practice/`. Practice Type options are listed in
`tools/build-unit5-pages.py`. No page stores the selected Practice Type (no storage or URL parameter); a stale value
can only come from the browser restoring a form.

Review (W): topics 20/20/20/20/10/10, difficulty 40/40/20, independent.

Site convention for calculator pages (Unit 3): a sibling `calculator-practice/` folder, launch buttons with the
calculator icon (`bm-practice-icon-calculator`), analytics ids with `_calculator` / `_noncalculator` suffixes.
