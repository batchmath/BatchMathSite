## Exact rollback procedure

The previous site is permanently recoverable from **`safety/pre-v13.0g-im1-unit3-videos`**, pointing to **`d846d75a427b44cda4c7840e0e2c67054b533e43`**. A future owner-requested rollback uses a new restoration commit and a normal PR/merge, never reset or force-push. Run in a clean checkout; review concurrent production changes before intentionally restoring the complete previous tree:

```bash
git fetch origin refs/heads/main:refs/remotes/origin/main refs/heads/safety/pre-v13.0g-im1-unit3-videos:refs/remotes/origin/safety/pre-v13.0g-im1-unit3-videos
BASE=d846d75a427b44cda4c7840e0e2c67054b533e43
test "$(git rev-parse origin/safety/pre-v13.0g-im1-unit3-videos)" = "$BASE"
git switch -c rollback/v13.0g-to-approved-f origin/main
git restore --source="$BASE" --staged --worktree -- :/
test "$(git write-tree)" = "$(git rev-parse "$BASE^{tree}")"
git commit -m "Restore approved v13.0.F production tree"
git push -u origin rollback/v13.0g-to-approved-f
```

Open a normal PR from that restoration branch into main, record its exact head, require the complete production QA workflow to pass, confirm main has not changed concurrently, and merge using that expected head. Record the restoration and merge SHAs. Wait for GitHub Pages **Success** for the restoration merge, then verify https://batchmath.net/assets/app-version.json returns 13.0.F, the prior 18-page lesson contents match the baseline (the original five videos retained; 13 G additions absent), and the original MathLive/3D controls work. The rollback deletes G-only tracked files from the restored tree while retaining all evidence in Git history and the G development branch. If unattended rollback cannot safely complete, leave references intact and report the exact outstanding recovery step.
