## Limits and manual review

Video player/keyboard/layout tests simulate external YouTube responses because the managed network does not permit YouTube; actual YouTube availability and audio are not claimed. Browser checks use Chromium desktop and emulated phone sizes, not physical iOS/Safari. The 3D delivery smoke uses mouse rotation/wheel zoom at both widths; the full unchanged suites additionally passed actual emulated touch drag/pinch. Real MathJax/font fixtures are supplied locally to browser QA; normal site use downloads MathJax from its existing CDN.

For manual review:

1. Extract the ZIP, open a terminal inside `bm-v13.0.F`, run `py -m http.server 8000` (`python3` on Linux/macOS), and open `http://localhost:8000/`.
2. In IM1 Unit 3 Section 1 Parts A–E, play each clip on desktop and phone; confirm B is Common Difference and C is Explicit Formula, and check PDF/practice links.
3. Try Cross Sections and Solids of Revolution: Transparent/Opaque, Show/Hide Cross Section, drag/pinch or wheel zoom, Reset View and calculator/non-calculator placement rules. Enter and grade MathLive answers.
4. Review other Unit 6 practice pages. A later production stage requires explicit approval; this delivery performs no final sitewide production verification, main merge or deployment.
