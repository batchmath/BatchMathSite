# BatchMath v10.7 — Product and Quotient Rule expansion

This cumulative release includes the v10.6.3.AA Power Rule work and every earlier checkpoint.

## Practice content

- Preserved Basic and Using All Function Types selectors in both engines.
- Preserved the eight earlier advanced templates per engine; added varied factor pairings spanning polynomials, reciprocals, rational powers, radicals, six trigonometric functions, natural logarithms, logarithms with bases other than e, base-e and base-a exponentials, and six inverse trigonometric functions.
- Quotient families put the new types in either numerator or denominator where mathematically appropriate.
- Solutions identify u, v, u', v' and substitute into the appropriate rule.
- Added inverse trig function parsing and corresponding answer keypad buttons on these engines and Derivatives Comprehensive Review.
- Updated the corresponding Product and Quotient Rule generators in Derivatives Comprehensive Review; its mixed practice can draw from them.

## Verification

- New direct generator suite: 42,000 generated cases and over 250,000 independent numerical derivative checks, covering all factor families and both quotient positions.
- Existing derivative topic suite: 8,000 Basic and 8,000 All Function Types samples for each engine.
- Comprehensive Review 220,000 sample AP stress run, deep topic audit, keypad tests, and full non-browser site suite passed.
- Browser visual interaction was not run here.

## Suggested deployment recheck

1. Basic continues to generate polynomial product/quotient problems.
2. Using All Function Types regularly shows logs with explicit bases, e and other exponential bases, all six trig functions, and inverse trig functions.
3. Quotient problems place new functions in both numerator and denominator.
4. Explanations show both factor derivatives and use the correct product/quotient formula.
5. The keypad inserts inverse trig functions, and typed equivalent forms receive credit.
6. In Comprehensive Review, choose Product Rule and Quotient Rule separately, then check that Mixed also serves the expanded families.
7. Enter checks and advances only once after feedback.
