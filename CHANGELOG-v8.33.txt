BatchMath v8.33
Built from v8.32

Calculus Prep refinements

Function Graphs
- Reduced the graph display size again (desktop max 440 px; mobile max 380 px).
- Rational-function equation choices now use a true stacked fraction display rather than slash notation.
- Rational-function correct-answer feedback preserves the same stacked fraction formatting.
- Logarithmic graph equations display logarithm bases as true subscripts.

Function Domains
- Removed Polynomial from the domain engine and from Mixed practice.
- Renamed Inverse Trig to Inverse Trigonometric Functions.
- Added nontrivial arguments to regular trigonometric-domain questions (for example sin(3x), cos(2x + pi/3), tan(2x), sec(4x), csc(3x), cot(2x)).
- Preserved the existing Combined / Composite problem families, changing only mathematical presentation/zero cleanup.
- Rational-function domain questions now display rational functions with stacked fraction bars.
- Radical displays now use a true vinculum over the entire radicand.
- Removed generated forms such as x - 0, x + 0, and 0 - x.

Logarithm Rules
- Logarithm bases now display as actual subscripts instead of strings such as log_b or log_2.
- Stacked fraction rendering is used where a complete displayed answer is a quotient (including change-of-base answers).

Site-wide Calc Prep math presentation
- Added shared rendering for logarithm subscripts, exponents, stacked fractions, and radicals with a vinculum extending over the radicand.
- Updated choice buttons and feedback to use the shared math renderer.
- Preserved existing preformatted stacked-fraction HTML where engines already provide it.
- Updated exact-answer radical display so typed square-root expressions also show the vinculum.
- Existing AP Calculus and IM1 practice pages already use MathJax/stacked fractions for their displayed rational expressions and radicals; those implementations were retained.

Algebra for Calculus / Unit Circle / Trig
- Algebra for Calculus radical and conjugate choices now use the improved radical display.
- Unit Circle and Trig Angle Skills exact radical values use the improved radical display.
- Trig Equation questions and feedback use the improved math renderer.

Rational Function Analysis
- Prevented factored forms from displaying x - 0; a zero root/factor is displayed as x.

QA
- JavaScript syntax checked across all asset scripts.
- Internal links, local assets, duplicate HTML ids, sitemap targets, and canonical targets checked.
- Searched Calc Prep and existing course engines for remaining risky +/- 0 formatting patterns.
