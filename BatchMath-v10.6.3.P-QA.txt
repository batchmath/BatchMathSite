BatchMath v10.6.3.P — Classifying Discontinuities Strict-Inequality Rendering Fix
===============================================================================

STATUS
------
PASS for the targeted rendering regression checks and release gates run for this patch.

CHANGE
------
- Fixed the Classifying Discontinuities piecewise-problem JavaScript escaping bug that caused
  strict inequalities to lose their TeX backslashes at runtime (for example, source `x\lt 0`
  becoming visible `xlt 0`).
- All strict less-than / greater-than commands in the two piecewise discontinuity families are
  now double-escaped in JavaScript source so MathJax receives `\lt` / `\gt` correctly.
- Inclusive inequalities (`\le`, `\ge`) remain unchanged and continue to render correctly.
- Classifying Discontinuities generatorVersion bumped to 5.
- Sitewide feedback MathJax normalization now recognizes `\lt` / `\gt` as well.
- Browser/MathJax audit command detection now includes `\lt` / `\gt`.
- Display-safety QA now fails on any unescaped JavaScript-source `\lt` / `\gt` token, preventing
  this exact failure class from silently returning in a future practice engine.
- Specialized calculus QA now checks the generated runtime TeX for the expected strict inequality
  commands in both affected piecewise families.
