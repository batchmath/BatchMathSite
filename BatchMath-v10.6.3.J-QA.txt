================================================================================

STATUS
------
PASS for all non-browser release gates and targeted engine QA run for this checkpoint.
Browser/human smoke testing remains the final publish gate; GitHub Actions should run the corrected seeded-browser harness.

CHANGES
-------
1. Classifying Discontinuities
- Rebuilt as a location-first, multi-discontinuity cycle.
- Student enters a discontinuity location before any classification is revealed.
- A correct location opens three classification buttons: Removable, Jump, Infinite.
- Classification buttons use green/red correct/incorrect highlighting.
- A wrong location reveals one actual remaining discontinuity and explains its type and reason.
- After each resolved discontinuity, student chooses No More Discontinuities or Input Another Discontinuity.
- The cycle repeats until the student correctly indicates there are no discontinuities left.
- Problem families include single and multiple removable, jump, and infinite discontinuities.

2. Difference Quotient
- Removed derivative-limit evaluation prompts from the Difference Quotient engine.
- Practice now asks only to simplify one of the two intended difference-quotient forms.
- Expanded/retained linear, polynomial, radical, and reciprocal families.
- Math in choices and explanations is wrapped for MathJax so raw strings such as \\frac{...} no longer display as text.

3. Product Rule / Quotient Rule
- Each selector now has exactly two categories: Basic and Using All Function Types.
- Basic uses only very simple polynomial pieces.
- Using All Function Types mixes polynomial, trig, logarithmic, exponential, radical, and genuine chain-rule compositions.
- Matching comprehensive-review copies use the same updated generators.

4. Trig Derivatives
- With Chain Rule now includes non-polynomial inner functions and multiple chain-rule layers, not just simple polynomial arguments.
- Includes nested exponential, logarithmic, radical, and trig compositions.

5. Chain Rule
- Selector now has four categories:
  * Simple Chain Rule
  * Multiple Applications of Chain Rule
  * Chain Rule with Other Rules
  * Everything Combined
- Multiple Applications contains pure nested-composition chain-rule problems only.
- Product/quotient combinations are placed in Chain Rule with Other Rules.
- Everything Combined mixes all three categories.
- Student-facing prompt is consistently "Find the derivative."
- Display formatting suppresses coefficient 1 (for example, no 1x).
- Matching comprehensive-review copies use the updated derivative generators.
