BatchMath v10.6.3.I — Limits at Infinity Variety + IVT Explanation Cleanup
==========================================================================

STATUS
------
PASS for all non-browser release gates run locally.

CHANGES
-------
1. Limits at Infinity
- Expanded the pure Limits at Infinity engine from 15 to 22 major families.
- Increased the radical-heavy share to approximately 50% of generated problems.
- Added substantially broader square-root structures, including:
  * sqrt(quadratic) / linear
  * linear / sqrt(quadratic)
  * sqrt(quadratic) / sqrt(quadratic)
  * conjugate finite-limit forms
  * reciprocals of conjugate finite-limit forms
  * sqrt(quadratic) / quadratic
  * quadratic / sqrt(quadratic)
  * sqrt(linear) / linear
  * linear / sqrt(linear)
  * sqrt(linear) / sqrt(quadratic)
  * sqrt(quadratic) / sqrt(linear)
- Quadratic radicands now commonly contain nonzero linear terms and varied constants rather than only simple k^2 x^2 + c forms.
- Retained polynomial, exponential-growth comparison, logarithmic-composition, exponential-composition, and reciprocal-log families.
- Positive-infinity versus negative-infinity generation now uses a balanced two-problem direction bag, guaranteeing one of each direction per pair of infinity-generator calls while randomizing the order.
- Matching infinity generator copies used by the Unit 1 comprehensive-review infrastructure were kept synchronized.

2. Intermediate Value Theorem
- Rewrote IVT feedback/explanations so all mathematical notation in explanations is inside MathJax delimiters.
- Rational endpoint values, intervals, c-values, roots, and function-value statements now render as math rather than exposing raw TeX-like text.
- IVT generatorVersion advanced to 5.
