BatchMath SAT & ACT Math Practice P2
Development preview for owner review. Website publication authorization is pending.

Local review
1. Extract bm-sat-act-p2.zip.
2. Open the extracted folder bm-sat-act-p2, which contains index.html.
3. On Windows, click the File Explorer address bar, type cmd and press Enter.
4. Run py -m http.server 8000
   On macOS or Linux, run python3 -m http.server 8000
5. Open http://localhost:8000/ in your browser. Keep the terminal open.
   Use Ctrl+C to stop the server. Internet access is needed for MathJax.

Review the homepage link, then open http://localhost:8000/sat-act-math/.
- Select a difficulty and check the topic cards and mixed-practice count.
- Start Mixed Practice and work through a set. The set ends with a session summary.
- Answer incorrectly, then retry correctly. The score reflects the first answer.
- Open a written solution before answering. The question is recorded as unscored.
- Check the numbered questions at http://localhost:8000/sat-act-math/problems/.
- Try a narrow browser window or your browser's phone emulator.

The preview includes all five questions and their written solutions. Real YouTube
links can be added after each matching public upload is verified. The publishing
workflow lists the five source IDs and cue times.

The site uses the BatchMath GA4 tag. Append ?bm_debug=1 during manual analytics
testing. See docs/sat-act/GA4-ANALYTICS.md.
