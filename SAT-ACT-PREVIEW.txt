BatchMath — SAT & ACT Math Practice prototype (sat-act-p1)
PRIVATE DEVELOPMENT PREVIEW. Not approved for publication. Do not deploy.

Windows local preview
1. Extract bm-sat-act-p1.zip.
2. Open the extracted folder bm-sat-act-p1 (the one that contains index.html).
3. In File Explorer, click the address bar, type cmd and press Enter. A terminal opens in that folder.
4. Run exactly:

   py -m http.server 8000

   (macOS or Linux: python3 -m http.server 8000)
5. Open http://localhost:8000/ in Chrome, Edge or Firefox. Keep the terminal open; stop it with Ctrl+C.
   Use the http://localhost address, not a double-clicked file: the pages use site-root paths.
   An internet connection is needed for math rendering (MathJax), as on the rest of the site.

Things to try
- Start Mixed Practice and work through all five: no question repeats, "Next Problem" becomes "Finish Session" on the
  last one, and the summary shows "X correct out of Y answered on the first try".
- Answer a question wrong, then right: the score keeps the first (wrong) answer.
- Open "Show the step-by-step solution" before answering: the question is marked "not scored".
- Click a topic's Practice button: a one-question topic finishes with "That's every question currently available...".
- Change the Exam or Difficulty filter on the library home; the counts update.
- Resize to phone width or use the browser's device toolbar.

About videos
None of the five videos is approved or published, so no YouTube IDs exist yet. The pages therefore show the written
solution directly (the normal "no video yet" state). The video player, its explanation start times (0:19, 0:16, 0:20,
0:23, 0:18), the "Show Written Solution" button and the automatic solution on video end are built and tested with a
simulated YouTube player; they switch on automatically once an approved video's real ID is added.

Analytics
Pages use the live BatchMath GA4 tag. While testing, add ?bm_debug=1 to a URL (for example
http://localhost:8000/sat-act-math/?bm_debug=1) to see each event in a panel and in GA4 DebugView.
See docs/sat-act/GA4-ANALYTICS.md.

About this package
bm-sat-act-p1.zip is a short preview package: the complete site from the branch commit, minus the classroom PDF
downloads of the other courses (about 310 MB, unchanged from main), so those PDF links show "not found" in this preview.
The review documents are included in docs/sat-act/:
  SAT-ACT-P1-REPORT.md     implementation and QA report, remaining steps
  GA4-ANALYTICS.md         events, custom definitions to register, DebugView checks
  PUBLISHING-WORKFLOW.md   approval boundary, adding approved problems
  APPROVED-EXPORT-SPEC.md  the approved-content export the production importer accepts
Build tools and QA (tools/sat-act/) are on the branch, not in this package.
