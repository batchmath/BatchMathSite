#001 Find tan B Given sin A = 15/17

  • Geometry and Trigonometry › Right-Triangle Trigonometry
  • Medium
  • Also practices: Pythagorean Theorem

Original BatchMath practice question · not an official SAT® or ACT® question

In right triangle \(ABC\), \(\angle C = 90^\circ\).

\[\sin A = \dfrac{15}{17}\]

What is \(\tan B\)?

Your answer: A

\(\frac{8}{17}\) is opposite ÷ hypotenuse for angle \(B\), which is \(\sin B\); \(\tan B\) needs opposite ÷ adjacent, \(\frac{8}{15}\).

Your answer: C

\(\frac{15}{17}\) is opposite ÷ hypotenuse for angle \(A\), which is \(\sin A\) (the given ratio); \(\tan B\) needs opposite ÷ adjacent, \(\frac{8}{15}\).

Your answer: D

\(\frac{15}{8}\) uses the opposite and adjacent sides relative to angle \(A\), not angle \(B\), so it is \(\tan A\); \(\tan B\) is \(\frac{8}{15}\).

  1. Step 1 Watch the angles

    Watch the angles! Given: \(\sin A\). Asked: \(\tan B\).

  2. Step 2 Use the given ratio

    SOH CAH TOA: \(\sin = \dfrac{\mathrm{opposite}}{\mathrm{hypotenuse}}\). From \(A\), the opposite side is \(BC\).

    Any size has the same ratios, so use \(BC = 15\), \(AB = 17\).

    \[\sin A = \dfrac{BC}{AB} = \dfrac{15}{17}\]

  3. Step 3 Shortcut: a Pythagorean triple

    Shortcut: \(8\), \(15\), \(17\) is a Pythagorean triple.

    \[AC = 8\]

  4. Step 4 Check with the Pythagorean theorem

    No triple? Use the Pythagorean theorem.

    \[AC^2 = 17^2 - 15^2 = 64\]
    \[AC = \sqrt{64} = 8\]

  5. Step 5 Now look at angle B

    Now look at angle \(B\): opposite and adjacent switch.

    \[\text{opposite } B = AC = 8\]
    \[\text{adjacent } B = BC = 15\]

  6. Step 6 Calculate tan B

    SOH CAH TOA: \(\tan = \dfrac{\mathrm{opposite}}{\mathrm{adjacent}}\).

    \[\tan B = \dfrac{AC}{BC} = \dfrac{8}{15}\]

  7. Step 7 The trap: tan A

    The trap: using angle \(A\) gives \(\tan A\), choice D.

    \[\tan A = \dfrac{BC}{AC} = \dfrac{15}{8}\]

Answer

B · \(\dfrac{8}{15}\)

Key Idea

Opposite and adjacent depend on which angle you use.

Why the other choices are wrong
  • A · \(\dfrac{8}{17}\): \(\frac{8}{17}\) is opposite ÷ hypotenuse for angle \(B\), which is \(\sin B\); \(\tan B\) needs opposite ÷ adjacent, \(\frac{8}{15}\).
  • C · \(\dfrac{15}{17}\): \(\frac{15}{17}\) is opposite ÷ hypotenuse for angle \(A\), which is \(\sin A\) (the given ratio); \(\tan B\) needs opposite ÷ adjacent, \(\frac{8}{15}\).
  • D · \(\dfrac{15}{8}\): \(\frac{15}{8}\) uses the opposite and adjacent sides relative to angle \(A\), not angle \(B\), so it is \(\tan A\); \(\tan B\) is \(\frac{8}{15}\).
