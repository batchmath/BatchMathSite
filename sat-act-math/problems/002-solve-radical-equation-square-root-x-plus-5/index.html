#002 Solve the Radical Equation √(x + 5) = x − 7

\[\sqrt{x + 5} = x - 7\]

Which choice lists all real solutions of the equation?

Your answer: A

\(x = 4\) solves the squared equation, but in the original equation \(\sqrt{4 + 5} = 3\) while \(4 - 7 = -3\), so \(4\) is extraneous.

Your answer: C

\(x = 11\) is a solution, but \(4\) is not: it makes the left side \(3\) and the right side \(-3\), so the list includes an extraneous value.

Your answer: D

\(x = 11\) satisfies the original equation: \(\sqrt{11 + 5} = 4\) and \(11 - 7 = 4\), so a real solution exists.

  1. Step 1 Square both sides

    Squaring can create extra solutions, so we will check them at the end.

    \[x + 5 = \htmlClass{hlbox}{(x - 7)^2}\]

  2. Step 2 Expand and rearrange

    Careful: \((x - 7)^2 = x^2 - 14x + 49\), not \(x^2 + 49\).

    \[x + 5 = \htmlClass{hlbox}{x^2 - 14x + 49}\]
    \[0 = x^2 - 15x + 44\]

  3. Step 3 Factor

    Product \(44\), sum \(-15\): use \(-4\) and \(-11\).

    \[0 = (x - 4)(x - 11)\]

    Candidates · not answers yet

    \[x = 4\ \text{or}\ x = 11\]

  4. Step 4 Test x = 11

    Substitute into the original equation.

    \[\sqrt{11 + 5} \stackrel{?}{=} 11 - 7\]
    \[4 = 4\]

    This value checks.

  5. Step 5 Test x = 4

    Substitute into the original equation.

    \[\sqrt{4 + 5} \stackrel{?}{=} 4 - 7\]
    \[3 \neq \htmlClass{hlbad}{-3}\]

    This value does not check.

  6. Step 6 Why did 4 appear?

    A principal square root is never negative, so it can't equal \(-3\).

    Squaring hid the sign, so \(4\) slipped in.

    \[3^2 = (-3)^2 = 9\]

Answer

B · \(11\)

Key Idea

Squaring both sides can create extraneous solutions. Always check every candidate in the original equation.

Why the other choices are wrong
  • A · \(4\): \(x = 4\) solves the squared equation, but in the original equation \(\sqrt{4 + 5} = 3\) while \(4 - 7 = -3\), so \(4\) is extraneous.
  • C · \(4\) and \(11\): \(x = 11\) is a solution, but \(4\) is not: it makes the left side \(3\) and the right side \(-3\), so the list includes an extraneous value.
  • D · No real solution: \(x = 11\) satisfies the original equation: \(\sqrt{11 + 5} = 4\) and \(11 - 7 = 4\), so a real solution exists.
