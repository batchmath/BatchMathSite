#006 Advanced Math · Quadratics

Original BatchMath practice question · not an official SAT® or ACT® question

In the equation below, \(c\) is a constant.

\[x^2 - 8x + c = 0\]

For what value of \(c\) does the equation have exactly one real solution?

Your answer: A

With \(c = -16\), \(b^2 - 4ac = 64 - 4(-16) = 128\), which is positive, so the equation has two real solutions.

Your answer: B

With \(c = 4\), \(b^2 - 4ac = 64 - 4(4) = 48\), which is positive, so the equation has two real solutions.

Your answer: D

With \(c = 64\), \(b^2 - 4ac = 64 - 4(64) = -192\), which is negative, so the equation has no real solutions.

  1. Step 1 What the discriminant tells you

    The discriminant \(b^2 - 4ac\) counts the real solutions: positive, two; zero, exactly one; negative, none. Careful: here \(b = -8\).

  2. Step 2 Set it equal to $0$

    Here \(a = 1\). Watch the sign: \((-8)^2 = 64\).

    \[(-8)^2 - 4(1)c = 0\]
    \[64 - 4c = 0\]
    \[c = 16\]

  3. Step 3 Shortcut: a perfect square

    Shortcut: half of \(-8\), squared. Then the left side is a perfect square, so its only root is \(x = 4\).

    \[\left(\dfrac{-8}{2}\right)^2 = 16\]
    \[x^2 - 8x + 16 = (x - 4)^2\]

Answer

C · \(16\)

Key Idea

A quadratic (\(a \neq 0\)) has exactly one real solution when its discriminant \(b^2 - 4ac\) equals \(0\).

Why the other choices are wrong
  • A · \(-16\): With \(c = -16\), \(b^2 - 4ac = 64 - 4(-16) = 128\), which is positive, so the equation has two real solutions.
  • B · \(4\): With \(c = 4\), \(b^2 - 4ac = 64 - 4(4) = 48\), which is positive, so the equation has two real solutions.
  • D · \(64\): With \(c = 64\), \(b^2 - 4ac = 64 - 4(64) = -192\), which is negative, so the equation has no real solutions.
