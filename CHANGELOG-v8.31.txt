2. UNIT CIRCLE EXACT VALUES ENGINE
============================================================
Separated exact unit-circle trig values into their own dedicated engine.

Trig-function options:
- Sine only
- Cosine only
- Tangent only
- Cosecant only
- Secant only
- Cotangent only
- Sine / Cosine / Tangent
- Cosecant / Secant / Cotangent
- All six trig functions

Angle-format options:
- Radians
- Degrees
- Mixed

Angle-set options:
- Quadrant I
- Quadrant II
- Quadrant III
- Quadrant IV
- All Four Quadrants (includes standard axis angles)

Answer behavior:
- exact answers only
- decimal approximations are rejected
- equivalent exact radical/fraction forms are accepted
- optional radical parentheses are accepted (examples: √2, √(2), and an unfinished √(2 entry)
- undefined reciprocal/quotient values are supported
- stacked fraction answer editor/keypad is included

- Simplify / Rewrite
- Mixed

============================================================
5. SYNTHETIC DIVISION & RATIONAL ROOT THEOREM ENGINE
============================================================
Built using "03 - Synthetic Division and the Rational Root Theorem.pdf" as the model.

Requested modes:
- Possible Rational Roots: students list the complete reduced ±p/q candidate set
- Synthetic Division: students supply the quotient and remainder

Additional mode added:
- Factor Test / Remainder: students decide whether x-a is a factor using the remainder

Additional control added:
- Cubic / Quartic / Mixed degree

Answer handling:
- Rational Root Theorem lists may be entered in any order
- ± shorthand is accepted
- duplicate equivalent fractions are reduced/normalized
- synthetic-division quotient answers are checked algebraically rather than by exact text only

============================================================
6. SPECIAL FACTORING ENGINE
============================================================
Built around "02 - Special Factoring Cases Review.pdf" and expanded for calculus preparation.

Requested categories:
- Difference of Squares
- Sum / Difference of Cubes
- Perfect Square / Perfect Cube / Perfect Fourth-Power patterns
- Higher-order factoring that repeatedly uses differences of squares/cubes
- Pascal's Triangle coefficients for (a ± b)^n
- Factoring by Grouping
- Factoring by Substitution

Pascal's Triangle:
- standard mode uses natural-number exponents through 8
- advanced mode extends through exponent 12
- subtraction cases require alternating signed coefficients

Additional category added:
- GCF + Special Pattern, requiring students to remove a GCF before using a special factoring identity

Additional control added:
- Standard / Advanced difficulty

Factoring answers are checked for polynomial equivalence AND for actually being written in factored form. Retyping the original expanded polynomial is not accepted.

============================================================
7. FUNCTION GRAPHS ENGINE
============================================================
Created a canvas-based graphing practice engine rather than a static worksheet-style question bank.

Function families:
- Polynomial
- Rational
- Exponential
- Logarithmic
- Trigonometric
- Mixed

Question types:
- Identify the Equation
- Analyze a Key Feature
- Mixed

Dynamic graph features include:
- polynomial vertices and end behavior
- rational vertical/horizontal asymptotes
- exponential horizontal asymptotes
- logarithmic vertical asymptotes and domains
- trig amplitude, midline, and period
- transformed functions generated with randomized parameters
- dynamically drawn axes, grid, curves, and asymptote guides

A duplicate-choice issue discovered during visual QA was corrected so generated multiple-choice sets contain unique options.

10. RATIONAL FUNCTION ANALYSIS ENGINE
============================================================
Each generated rational-function problem asks students to determine:
- hole(s)
- vertical asymptote(s)
- horizontal or slant asymptote
- x-intercept(s)

Requested core content:
- holes
- asymptotes

Additional features added:
- factored / expanded / mixed display forms
- advanced slant-asymptote problems
- x-intercepts, so students distinguish canceled numerator zeros from surviving numerator zeros
- Basic / Advanced difficulty control

A malformed hole distractor discovered during QA was removed.

============================================================
11. TRIGONOMETRIC EQUATIONS ENGINE
============================================================
All answers are exact and all solutions must be given on [0, 2π).
Decimals are rejected.

Categories:
- Basic trig equations
- Multiple-angle equations such as sin(3x)=1/2
- Factoring / common-factor trig equations
- Quadratic-in-a-trig-function equations
- Identity conversion before solving/factoring
- Mixed

The multiple-angle solution generator was specifically tested across sine, cosine, and tangent standard exact values for multipliers 1 through 4. A missing sin(kx)=0 branch was found during QA and corrected before release.
